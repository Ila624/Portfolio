# Global Trends Analysis: Energy, Demographics & Migration Insights

This project delivers a comprehensive data analysis using SQL (PostgreSQL) to uncover global correlations between sustainable energy development, country-specific quality-of-life metrics, and international migrant incidents. The insights are supported by a visual presentation mapping key historical trends from 2000 to 2023.

## 📊 Core Analytical Themes
* **Energy Transition (2000-2020):** Tracking global consumption shifts from fossil fuels to nuclear and renewable energy sources across 195 countries.
* **Socio-Economic Correlations:** Utilizing JOIN operations to evaluate the relationship between basic utility infrastructure (electricity access) and vital human metrics (life expectancy and infant mortality).
* **Migrant Crisis & Seasonality:** Aggregating incident frequencies, identifying reporting anomalies (e.g., the 2023 data truncation), and mapping casualties by country and regional origin.
