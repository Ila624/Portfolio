# Sustainable Development Goals: A Data-Driven Analysis
*An analysis of global energy consumption, quality of life, and migration trends (2000–2023).*

---

## 📌 Project Overview
This project delivers a comprehensive, data-driven analysis centered on the United Nations' **Sustainable Development Goals (SDGs)**. By leveraging SQL for data cleaning and integration, and data visualization tools for reporting, the analysis explores how global development has evolved over the last two decades. 

## 💻 SQL Code & Queries
The complete SQL script containing the data cleaning, preprocessing, and `JOIN` operations performed for this project is available directly in this repository:

👉 **[View SQL Queries Script](Sql_project.sql)**

The study is divided into three interconnected dimensions:
1. **World Energy Consumption (2000–2020):** Tracking the global energy mix (fossil fuels, nuclear, and renewables) and analyzing infrastructure expansion alongside population growth.
2. **Quality of Life Metrics:** Utilizing SQL `JOIN` operations to correlate socioeconomic factors (life expectancy and infant mortality) with electricity access, uncovering a critical global divide.
3. **Global Migration Trends (2014–2023):** Investigating humanitarian incident data to map migration corridors, examine seasonal patterns, and analyze primary causes of casualty in relation to regional geopolitical instabilities.

## 💾 Datasets Used
The analysis was performed by cleaning, querying, and merging three distinct public datasets:

1. **Global Data on Sustainable Energy (2000–2020):** Contains world tracking metrics for electricity access, renewable energy shares, and infrastructure development.  
   👉 **[Dataset Source](https://www.kaggle.com/datasets/anshtanwar/global-data-on-sustainable-energy)**
2. **Global Country Information (2023):** Integrates major socioeconomic indicators including life expectancy, infant mortality, healthcare density, and demographics.  
   👉 **[Dataset Source](https://www.kaggle.com/datasets/nelgiriyewithana/countries-of-the-world-2023)**
3. **Global Missing Migrants Dataset (2014–2023):** Tracks international migration incidents, capturing spatial data, regions of origin, and casualty metrics.  
   👉 **[Dataset Source](https://www.kaggle.com/datasets/nelgiriyewithana/global-missing-migrants-dataset)**
